# FORM / 01 海报排版工作室

这是一个在浏览器中运行的自动海报排版器。无需安装；文字、图片与抠图过程都留在本机浏览器中。

## 怎么用

1. 双击 `启动海报工作室.bat`。也可以直接打开 `index.html`；如浏览器限制本地 AI 模型加载，请改用启动器。
2. 在左侧选择一种视觉风格；默认是新增的“纯白平面”。
3. 填写主标题、副标题、日期、地点和简介。
4. 可选：拖入 1–4 张自己的图片或素材；上传后按住左侧缩略图，可以直接拖到右侧海报的任意位置。
5. 图片放入海报后仍可移动和缩放；也可点“一键抠图”，识别完成后直接排版、恢复原图，或单独下载透明 PNG。
6. 从内置拼贴素材库添加胶带、撕纸、网点、涂鸦等元素，也可以点“随机组合”。
7. 可继续加入工具类或表情类 Emoji；同一个 Emoji 可以重复加入。
8. 点击“版面部件”、拼贴素材或 Emoji 后，在右侧海报上直接拖动；使用黑色工具条缩放、复位或删除。
9. 选择画布尺寸、颜色、信息密度和素材尺寸。
10. 点击“换个版式”生成同一风格的另一种构图；手动摆放过的部件会保留当前位置。
11. 点击“导出 PNG”保存海报。

快捷键：`R` 随机版式；方向键微调当前元素；`Shift + 方向键` 大步移动；`Delete` 删除当前元素；`Ctrl / Cmd + S` 导出 PNG。

## 自由调整版面

左侧“版面部件”提供眉题、主标题、副标题、主图/主视觉、日期、时间、地点、简介、署名和二维码。工坊模板还会出现课程区。

- 点击部件按钮，或直接点击海报中的部件，即可进入调整状态。
- 在海报中拖动改变位置；黑色工具条的 `− / ＋` 调节当前元素大小，`↺` 恢复自动位置，`×` 隐藏或移除。
- 被隐藏的文字或图片部件可以再次点击“版面部件”中的对应按钮恢复。
- 上传图片归入“主图 / 主视觉”；既可以从左侧素材卡直接拖到海报落点，也可以在画布上继续自由拖动和缩放。
- 拼贴素材、每一个 Emoji 也都是独立元素，位置与大小会自动保存。

## AI 主体抠图

- 每张图片素材卡都有“一键抠图”。完成后卡片会显示透明棋盘格，并自动把透明主体用于当前海报。
- 点“恢复原图”可随时撤销；点右侧下载图标可保存单独的透明 PNG。
- 首次使用需联网加载轻量模型（约 40 MB），浏览器缓存后再次使用会更快。
- 模型直接在浏览器内运行，原始图片不会发送到远程服务器。复杂发丝、玻璃与半透明物体仍可能需要专业软件做精修。

## 内置拼贴素材

素材库包含 12 种可程序化生成的元素：胶带、撕纸、网点、涂鸦、爆炸贴、箭头、印章、条码、网格片、靶心、碎纸和彩色渐变球。

- 可同时叠加最多 8 种素材。
- “随机组合”会挑选 3–5 种并自动布局；“清空”移除全部素材。
- “整体尺寸”可统一调节拼贴素材和 Emoji 的大小。
- 所有素材均为程序绘制，因此在 A4 等高分辨率导出时仍保持清晰。

Emoji 素材库另含两组：工具/创作类（工具、扳手、剪刀、尺子、画笔、相机等）与表情/氛围类（笑脸、思考、机器人、闪光、爆炸等）。点击即可加入，并可重复添加。

## 内置视觉方向

- **纯白平面**：新增的默认模板。纯白底、黑色信息层级和单一强调色，接近可继续自由编辑的设计底稿。
- **ICI · 格栅实验**：浅色工程网格、粗黑双语标题和纯色几何主视觉。
- **ICI · 电光流体**：恢复上一版的钴蓝底、超大白字、紫色高光流体与上下循环信息带，同时保留新版自由拖动。
- **瑞士秩序**：十二栏网格、非对称对齐、红黑几何和严格的信息层级。
- **编辑部**：已重做为纯白底、衬线标题、细竖线与克制图文分栏。
- **新拼贴**：高饱和纯色色块、粗体标题和可自由叠加的拼贴元素。
- **静默留白**：已重做为纯白底、宋体/衬线字、低对比度圆形和大面积呼吸空间。
- **经典构图实验**：把四角、对角、包围等方法转化为对齐和节奏关系；成品不显示教学图片中的引导斜线。
- **蓝字展讯**：灰白底、钴蓝信息流、大面积留白与荧光绿时间栏。
- **构图图谱**：近白纸张、黑色衬线字与低对比度圆形系统。
- **工坊拼豆**：以可自由移动、缩放的彩色拼豆图案作为版面主视觉；可选择 emoji 图案、上传二维码并调整主要版面部件。

## 工坊拼豆怎么用

选择“工坊拼豆”后，左侧会出现专用区域：

1. 用“添加课程”增加课程，或用每张课程卡右上角的 × 删除。
2. 每门课程可填写名称、时间地点和一句简介。
3. 图案可选 `01`、向上箭头、交叉 X、爱心或随机散点。
4. 输入任意 emoji 作为拼豆单元，例如 `👀`、`🟠`、`❤️`。
5. 可上传真实二维码；未上传时会自动生成装饰码。

## 调研依据

本工具没有复制任何单张海报，而是把公开案例中的构图方法提炼成可复用规则：

- Pinterest：Editorial Layout Typography、Swiss Typography Poster、Modern Collage Poster Design 等公开灵感集合。
- 厦门大学创意与创新学院：2024 ICI Degree Show 主视觉中的蓝色工程网格、粗黑双语信息、黑白紫抽象形体；学院活动回顾视觉中的钴蓝背景、白色超大字和紫色流体物。
- 学院公开报道和展览信息，用于确认 ICI Design Season、Degree Show、字体海报展等真实内容语境。
- 用户补充的构图教学、艺术展讯和米白构图图谱参考，用于新增四角/对角/包围/复合构图、蓝灰信息版式和低对比度有机形系统。
- 旧版 `工坊海报编辑器.html` 中的课程模块、emoji 图案预设、QR 上传和多尺寸导出逻辑，已重新设计后合并到新版。

## 文件

- `index.html`：程序入口
- `styles.css`：工作室界面样式
- `app.js`：自动排版、素材处理与导出逻辑

界面与排版使用原生 HTML / CSS / JavaScript。常规排版可离线使用；“一键抠图”首次运行会从 IMG.LY 的浏览器端背景移除组件加载模型文件。
