# FORM / 01 海报排版工作室

这是一个在浏览器中运行的自动海报排版器。无需安装；文字、图片与抠图过程都留在本机浏览器中。

## 怎么用

1. 双击 `启动海报工作室.bat`。也可以直接打开 `index.html`；如浏览器限制本地 AI 模型加载，请改用启动器。
2. 在左侧选择一种视觉风格；默认使用“成品模式”，每款模板会固定比例、核心构图和信息层级。
3. 填写该模板开放的主标题、副标题、日期、地点和简介；与用途无关的字段会自动停用。
4. 如需嘉宾、备注或额外口号，点击“添加文本”。成品模式最多 3 个，自由模式最多 8 个；每个文本框都可独立拖动、缩放、旋转和删除。
5. 可选：拖入 1–4 张自己的图片或素材；上传后按住左侧缩略图，可以直接拖到右侧海报的任意位置。
6. 图片放入海报后仍可移动和缩放；也可点“一键抠图”，识别完成后直接排版、恢复原图，或单独下载透明 PNG。
7. 从内置拼贴素材库添加胶带、撕纸、网点、涂鸦等元素；同一种素材可以连续点击添加多个，也可以点“随机组合”。
8. 可继续加入工具类或表情类 Emoji；同一个 Emoji 可以重复加入。
9. 需要进一步实验时切换到“自由模式”，即可点击“版面部件”、拼贴素材或 Emoji，在右侧海报上直接拖动，并使用黑色工具条缩放、复位、删除和旋转。
10. 选择画布尺寸、颜色、信息密度和当前素材尺寸。
11. 保持“智能参考线与吸附”开启：拖动部件时会显示中心线、安全边距、四分线及其他元素的中心/边缘对齐线，并在接近时自动吸附。
12. 点击“换个版式”生成同一风格的另一种构图；手动摆放过的部件会保留当前位置。
13. 点击“导出 PNG”保存海报。

快捷键：`R` 随机版式；方向键微调当前元素；`Shift + 方向键` 大步移动；`Delete` 删除当前元素；`Ctrl / Cmd + S` 导出 PNG。

## 成品模式与自由模式

- **成品模式（默认）**：面向真实活动生产。锁定模板比例、背景、主图落点、文字层级和品牌色；用户只替换与当前用途相关的内容、主图，并可增加最多 3 个补充文本框。
- **自由模式**：面向学习和视觉实验。恢复版面部件、字体字号、拼贴素材、Emoji、颜色、密度、参考线和自由尺寸等完整能力。
- 两种模式共用内容；切换到成品模式不会删除自由模式中的实验元素，只会在成品输出中暂时隐藏它们并恢复模板规则。

## 自由调整版面

左侧“版面部件”提供眉题、主标题、副标题、主图/主视觉、日期、时间、地点、简介、署名和二维码。“老师工坊课程表”还会出现可整体移动、缩放的课程区。

选中眉题、主标题、副标题、日期、时间、地点、简介或署名后，会出现“文字样式”面板。字体和字号按部件独立保存，切换风格时仍会保留，也可以一键恢复当前模板的默认文字样式。

- 点击部件按钮，或直接点击海报中的部件，即可进入调整状态。
- 在海报中拖动改变位置；黑色工具条的 `− / ＋` 调节当前元素大小，`↺` 恢复自动位置，`×` 隐藏或移除。
- 拖动时，青色虚线标出画布中心和安全边距；接近对齐位置时会出现粉色智能参考线并自动吸附。参考线只在编辑时出现，不会进入导出的 PNG。
- 被隐藏的文字或图片部件可以再次点击“版面部件”中的对应按钮恢复。
- 上传图片归入“主图 / 主视觉”；既可以从左侧素材卡直接拖到海报落点，也可以在画布上继续自由拖动和缩放。
- 拼贴素材、每一个 Emoji 也都是独立元素，位置、大小与角度会自动保存；选中后，“当前素材大小”滑杆只调整这一个实例，“当前元素角度”可在 −180° 到 180° 之间旋转。
- 导入的主视觉以及标题、日期、二维码等版面部件也可以独立调整角度。

## AI 主体抠图

- 每张图片素材卡都有“一键抠图”。完成后卡片会显示透明棋盘格，并自动把透明主体用于当前海报。
- 点“恢复原图”可随时撤销；点右侧下载图标可保存单独的透明 PNG。
- 首次使用需联网加载轻量模型（约 40 MB），浏览器缓存后再次使用会更快。
- 模型直接在浏览器内运行，原始图片不会发送到远程服务器。复杂发丝、玻璃与半透明物体仍可能需要专业软件做精修。

## 内置拼贴素材

素材库包含 18 种可程序化生成的元素：胶带、撕纸、网点、涂鸦、爆炸贴、箭头、印章、条码、网格片、靶心、碎纸、彩色渐变球，以及荧光绿平刷、荧光云团、黑色炭笔、炭笔花瓣、荧光弹簧线和自由轮廓线。

- 可同时添加最多 32 个素材，同一种素材可以重复添加；素材卡右上角会显示当前数量。
- “随机组合”会挑选 3–5 种并自动布局；“清空”移除全部素材。
- “当前素材大小”只调节当前选中的拼贴素材或 Emoji，不会改变其他元素。
- “当前元素角度”只旋转当前选中元素；新加入的素材默认为 0°，随机组合会保留轻微的随机倾斜。
- 所有素材均为程序绘制，因此在 A4 等高分辨率导出时仍保持清晰。
- 箭头已替换为蓝色粗圆角右箭头，匹配用户提供的透明 PNG 参考。

Emoji 素材库另含两组：工具/创作类（工具、扳手、剪刀、尺子、画笔、相机等）与表情/氛围类（笑脸、思考、机器人、闪光、爆炸等）。点击即可加入，并可重复添加。

## 内置视觉方向

- **纯白平面**：默认生产模板。纯白底、黑色信息层级和单一强调色，固定 3:4 骨架。
- **ICI · 格栅实验**：浅色工程网格、粗黑双语标题和纯色几何主视觉。
- **ICI · 电光流体**：恢复上一版的钴蓝底、超大白字、紫色高光流体与上下循环信息带，同时保留新版自由拖动。
- **科技系统发布**：IBM 系统设计启发的 2× 模块网格、蓝黑配色与严格信息序号，适合科技论坛、研究发布和报告封面。
- **人物宣言**：Apple 人物传播启发的黑白人物主图、左侧宣言和克制红色签名线，适合人物故事与嘉宾观点。
- **年度声音回顾**：Spotify Wrapped 启发的深色底、荧光渐变、同心声波和年度数据层级，适合音乐活动与年度总结。
- **产品极简发布**：Apple 产品传播启发的居中单品、大留白和精简发布信息，适合新品预告与单品介绍。
- **系统讲座**：IBM Town Hall 海报启发的双栏双行系统与蓝色信息区，适合讲座、论坛和议程发布。
- **蓝字展讯**：灰白底、钴蓝信息流、大面积留白与荧光绿时间栏。
- **构图图谱**：近白纸张、黑色衬线字与低对比度圆形系统。
- **工坊拼豆**：以可自由移动、缩放的彩色拼豆图案作为版面主视觉；可选择 emoji 图案、上传二维码并调整主要版面部件。
- **老师工坊课程表**：第 12 款模板。按老师原稿复刻为 9:16 纯白课程表，包含“工坊 👀 Tour”、学期日期、四组双栏课程、中央信号灯/警示条/QR 字样、粉色标点与底部学院署名。
- **荧光炭笔海报**：第 13 款模板。固定为经典 3:4，以空心大标题、黑色粗体、大面积纯白和右下荧光绿云团复刻用户确认的初始画面；绿色云团可独立移动和缩放，其余炭笔与曲线素材仍可按需从素材库重复添加。

## 工坊拼豆怎么用

选择“工坊拼豆”后，左侧会出现专用区域：

1. 图案可选 `01`、向上箭头、交叉 X、爱心或随机散点。
2. 输入任意 emoji 作为拼豆单元，例如 `👀`、`🟠`、`❤️`。
3. 可上传真实二维码；未上传时会自动生成装饰码。

## 老师工坊课程表怎么用

选择“老师工坊课程表”时，程序会切换到它独立保存的 9:16 画布，并带入参考原稿中的标题、日期、四门课程与学院署名。切换到其他模板后，会自动恢复原模板之前的比例、文字、位置和字体设置；再次回到老师模板时，老师模板自己的编辑结果也会保留。

1. 在“填写海报内容”中修改主标题、日期和底部署名。
2. 在专用课程区域修改每门课程的名称、英文名、时间、教室与简介，也可增删课程。
3. 点击“课程区”后，可在右侧海报中整体拖动或缩放四组课程与中央符号。
4. 主标题、日期和底部署名仍可分别调整位置、字体和字号。

## 荧光炭笔海报怎么用

选择“荧光炭笔海报”时，程序会切换到独立保存的经典 3:4 画布，默认只载入右下角的荧光绿云团。切换回其他模板会恢复之前的比例、文字与素材状态；再次进入第 13 款模板时，会继续保留该模板自己的编辑结果。

1. 空心主标题、黑色粗体副标题、正文和底部署名都可以单独拖动并更改字体或字号。
2. 荧光云团、炭笔花瓣、黑色炭笔、荧光弹簧线和自由轮廓线均是独立素材，可重复添加，并逐一移动、缩放、复位或删除。
3. 需要箭头时，点击素材库中的“箭头”即可加入蓝色粗圆角右箭头；连续点击可以加入多个。

## 调研依据

本工具没有复制任何单张海报，而是把公开案例中的构图方法提炼成可复用规则：

- Pinterest：Editorial Layout Typography、Swiss Typography Poster、Modern Collage Poster Design 等公开灵感集合。
- 厦门大学创意与创新学院：2024 ICI Degree Show 主视觉中的蓝色工程网格、粗黑双语信息、黑白紫抽象形体；学院活动回顾视觉中的钴蓝背景、白色超大字和紫色流体物。
- 学院公开报道和展览信息，用于确认 ICI Design Season、Degree Show、字体海报展等真实内容语境。
- 用户补充的构图教学、艺术展讯和米白构图图谱参考，用于新增四角/对角/包围/复合构图、蓝灰信息版式和低对比度有机形系统。
- 用户补充的荧光绿手绘营销海报参考，用于新增荧光绿/黑色炭笔素材系统与第 13 款 3:4 模板。
- 旧版 `工坊海报编辑器.html` 中的课程模块、emoji 图案预设、QR 上传和多尺寸导出逻辑，已重新设计后合并到新版。
- IBM Design Program 与 Carbon / IBM Design Language 的系统网格，用于“科技系统发布”和“系统讲座”：https://www.ibm.com/history/design-program 、https://www.ibm.com/design/language/layout/overview/
- Apple “Real People” 人物传播案例与长期产品传播方法，用于“人物宣言”和“产品极简发布”：https://www.apple.com/newsroom/2002/06/10Apple-Launches-Real-People-Ad-Campaign/
- Spotify Wrapped 官方年度视觉说明，用于“年度声音回顾”的受控高能色彩与模拟/数字纹理：https://newsroom.spotify.com/2025-12-03/wrapped-marketing-campaign/

## 文件

- `index.html`：程序入口
- `styles.css`：工作室界面样式
- `app.js`：自动排版、素材处理与导出逻辑

界面与排版使用原生 HTML / CSS / JavaScript。常规排版可离线使用；“一键抠图”首次运行会从 IMG.LY 的浏览器端背景移除组件加载模型文件。
